## 개발 목적
Flutter MobileAgent의 시각 언어를 현재 Android Compose 채팅 클라이언트에 독립적으로 재구현해 브랜드 일관성과 상태 가독성을 높인다.

## 개발 범위
공통 Compose 디자인 토큰과 앱 전역 테마를 추가하고, 활성 Agent 채팅 화면의 상단 영역·빈 상태 Hero Card·메시지 카드·Composer와 Runtime 상태 시트를 기능 변경 없이 스타일링한다.

## 제외 범위
- OAuth, Runtime, Gateway, Agent 상태 머신과 네트워크 계약 변경
- Claude 또는 신규 Agent 추가
- Flutter 소스·브랜드·이미지·폰트 자산의 직접 복사
- 실기기에서 실제 Runtime/OAuth 재시도, prompt, Stop, logout 실행
- 기존 Codex 전용 호환 UI의 정리·삭제

## 결정 기록
- 기준 시각 언어는 Paper `#F4F3ED`, Ink `#10120F`, Acid `#B9F227`, Slate `#31372F`로 고정한다.
- 참고 앱의 라이트 테마를 1차 기준으로 사용하고, 이번 범위에서 별도 다크 팔레트나 동적 색상을 추가하지 않는다.
- Flutter 구현을 복사하지 않고 Compose `ColorScheme`, `Typography`, `Shapes`와 project-owned component로 재구현한다.
- 작은 영문 상태 레이블과 높은 대비의 Hero Card를 사용하되, 한국어 본문과 Android 접근성 의미를 우선한다.
- Acid는 Ink 위 상태 배지·진행 표시·핵심 CTA에만 사용하고 일반 본문 텍스트 색상으로 사용하지 않는다.
